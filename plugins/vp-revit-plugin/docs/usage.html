Usage

How to use the Lightning Protection Plugin

Step-by-Step Workflow

Step 1. Preparing Lightning Rods (Masts)

Before starting, make sure lightning rods exist in the model:

  • Load a family containing lightning masts, or
  • Use masts that are already present in the project.

Step 2. Defining Masts for Calculation

  1. Select one or more mast types in the project.
  2. Click the “Include Lightning Rod” button (folder icon).

After this step, the plugin clearly understands which elements should be treated as lightning rods.

Step 3. Selecting Areas for Calculation

Select the areas that contain masts for which the lightning protection zone should be calculated.

Note: Selecting other categories does not affect the result.

Step 4. Running the Calculation

  1. Click “Perform Calculation”.
  2. Wait until the process finishes.

Recommendation: If you have more than 200 masts, run calculations in smaller groups for improved stability.

✅ Result: the lightning protection zone is created.

Optional: Creating an Alternative Zone with Safety Margin

  1. Select already generated protection zones.
  2. Click “Safety Zone Mesh”.

✅ This secondary mesh helps verify protection coverage with additional safety margin.

Managing Results

Locking Desired Results

If the generated zones look correct, it is recommended to Pin them to protect against accidental changes.

Clearing Unnecessary Results

Remove unwanted or intermediate geometry using “Clear Calculation Results”.

Viewing Current Model Status

Click “View Calculation Result” to see:

  • current calculation status,
  • a complete list of plugin-related elements in the model.

This allows checking the model without rerunning calculations.

Enjoy using the plugin!
